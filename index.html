How to use it

Sends personalized check-in texts to patients — one message, everyone gets their own. You never copy-paste a name again.

  1. Add your patientsPatients tab → + Add. Enter their name, choose whether you text a parent, the patient, or either, and add the phone number(s). Have a list? Use Import CSV.
  2. Write your messagesMessages tab → + Add. Type it once and tap the blanks — {first name}, {patient}, {doctor}, {office} — they fill in for each person. Set the doctor/office names (and make your own blanks) in Settings.
  3. SendSend tab → pick a message → check who gets it → Start sending. On iPhone, each text opens in Messages ready to go — tap the blue arrow. On a Mac you can auto-send the whole batch (see below).
Zero-tap on a Mac

On the send screen tap “Have a Mac? Download a file…”, then run the included send-imessages script once — the whole batch sends itself. Full steps are in the README.
